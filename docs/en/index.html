The origin story

BORN FROM A
BROKEN PROMISE

"Under my government, the poor will eat picanha (premium steak) again."

In 2022, a Brazilian presidential candidate made this promise to millions of voters. He won the election. Four years later, premium steak costs R$80/kg — roughly $15 USD. The poor still can't afford it. The promise became a meme. The meme became a blockchain.

The ticker is FazoL — a play on the Portuguese word for "string bean" (feijão), a humble staple food of the poor, combined with the letter L from the candidate's name and the gesture that became iconic in Brazilian politics.

Each block mined rewards 13 FazoL. Coincidentally — or not — 13 is the number of his political party. Every block is a gentle reminder.

Decentralized democracy

BLOCKCHAIN
VOTING SYSTEM

Beyond the meme, Mulacoin includes a real voting system recorded directly on the blockchain via OP_RETURN transactions. Transparent, immutable, and auditable by anyone in the world.

🔒

Immutable

Votes are permanently recorded on the blockchain. Impossible to alter or delete after confirmation.

🔍

Auditable

Anyone with the Mulacoin wallet and txindex=1 can independently verify every single vote.

🗳️

1 Address = 1 Vote

Each blockchain address can vote once per topic. Duplicate votes are automatically ignored by the protocol.

⚡

Real-Time Results

Results update automatically with each new block mined — approximately every minute.

MVOTE Protocol

# Creating a voting topic
MVOTE:1:CREATE:TOPIC_ID:title:option1|option2|option3:deadline

# Casting a vote
MVOTE:1:VOTE:TOPIC_ID:chosen_option

# Rule: first vote per address = valid | subsequent votes = ignored

CPU Mining

MINE WITH
ANY CPU

No GPU needed. No ASIC. Any standard computer can mine Mulacoin and earn FazoL.

1

Install cpuminer

Clone and compile pooler's cpuminer from GitHub — the standard CPU mining software.

2

Open your wallet

Start Mulacoin with -server=1 and create a receiving address starting with "M".

3

Start mining

Run minerd pointing to your local node and collect 13 FazoL per block you find.

./minerd -a scrypt -o http://127.0.0.1:23560 \
  -u YOUR_USER -p YOUR_PASS \
  --coinbase-addr=YOUR_M_ADDRESS -t 2
